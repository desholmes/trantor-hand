FONTLOG for the Trantor Caption font

This file provides detailed information on the Trantor Caption font software. This information should be distributed along with the Trantor Caption font and any derivative works.

Basic Font Information

Trantor Caption is a modified version of Foundation One v0.4 by Roger Sperberg (https://github.com/rsperberg/foundation-one), which is based on the lettering used on screen in Foundation, an Apple TV+ series, to mark a change of place or time. As required by the SIL Open Font License, it is published under a different name because "FoundationOne" is a Reserved Font Name.

The upstream font contains capitals, figures and most of the Basic Latin punctuation, in one weight; its lowercase slots held copies of the capitals. Trantor Caption adds a true lowercase, the missing Basic Latin symbols, the characters needed for UK English, and a SemiBold.

Supported Unicode: U+0020-007E, U+00A0, U+00A3-00A4, U+00B0, U+00C0-00C2, U+00C4, U+00C7-00CF, U+00D1-00D4, U+00D6, U+00D9-00DC, U+00E0-00E2, U+00E4, U+00E7-00EF, U+00F1-00F4, U+00F6, U+00F9-00FC, U+0131, U+2013-2014, U+2018-2019, U+201C-201D, U+2022, U+2026, U+20AC, plus U+274F, U+3000 and U+F8FE kept from upstream.

Weights: Regular (400) and SemiBold (600).

Trantor Hand, Trantor Caption and Trantor Mark make up the Trantor font series (https://github.com/desholmes/trantor-type). They are fan-made fonts based on lettering seen in Foundation, the Apple TV+ series based on the Isaac Asimov books, and are not affiliated with or endorsed by Apple, Skydance or the Asimov estate.

ChangeLog

28 October 2026 Trantor Caption version 1.000
- renamed from Foundation One (Reserved Font Name)
- added a lowercase a-z, drawn as centre-line skeletons with flat ends and stroked to match the capitals
- added the missing Basic Latin symbols: $ % * ^ _ ` ~
- added accented vowels, c cedilla and n tilde (lower and upper case), dotless i, pound sterling, euro, ellipsis, bullet, degree and no-break space
- added stylistic set ss01 (an e with a dot in place of its bar, like E)
- added a SemiBold, made by thickening the Regular outlines
- rebuilt kerning in GPOS: upstream capital pairs kept, lowercase pairs replaced
- new vertical metrics to fit descenders and accented capitals
- added WOFF2/WOFF webfonts and a CSS @font-face stylesheet

18-24 October 2021 (Roger Sperberg) Foundation One version 0.4
- created Github repository with ttf and source files, OFL and other information files and samples
- initial release to public (but not Github release)
