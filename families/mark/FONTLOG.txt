FONTLOG for the Trantor Mark font

This file provides detailed information on the Trantor Mark font software. This information should be distributed along with the Trantor Mark font and any derivative works.

Basic Font Information

Trantor Mark is a modified version of Foundation Logo v0.3 by Roger Sperberg (https://github.com/rsperberg/foundation-logo), which is based on the logo of Foundation, an Apple TV+ series. As required by the SIL Open Font License, it is published under a different name because "FoundationLogo" is a Reserved Font Name.

The upstream font contains capitals, figures and Basic Latin punctuation, in one weight; its lowercase slots held copies of the capitals and alternate capitals from the series' second, thinner logo. Trantor Mark keeps those alternates in stylistic set 1 and adds a true lowercase, the characters needed for UK English, and a SemiBold.

Supported Unicode: U+0020-007E, U+00A0, U+00A3, U+00B0, U+00C0-00C2, U+00C4, U+00C7-00CF, U+00D1-00D4, U+00D6, U+00D9-00DC, U+00E0-00E2, U+00E4, U+00E7-00EF, U+00F1-00F4, U+00F6, U+00F9-00FC, U+0131, U+2013-2014, U+2018-2019, U+201C-201D, U+2022, U+2026, U+20AC, plus U+3000 and U+F8FE kept from upstream.

Weights: Regular (400) and SemiBold (600).

Trantor Hand, Trantor Caption and Trantor Mark make up the Trantor font series (https://github.com/desholmes/trantor-type). They are fan-made fonts based on lettering seen in Foundation, the Apple TV+ series based on the Isaac Asimov books, and are not affiliated with or endorsed by Apple, Skydance or the Asimov estate.

ChangeLog

28 October 2026 Trantor Mark version 1.000
- renamed from Foundation Logo (Reserved Font Name)
- moved the alternate capitals E F K P S W X Y Z from the lowercase slots to stylistic set ss01 (also salt), keeping their kerning
- added a lowercase a-z, drawn as centre-line skeletons with flat ends and stroked to match the capitals
- added accented vowels (accented O's without the logo dot), c cedilla and n tilde (lower and upper case), dotless i, pound sterling, euro, ellipsis, bullet, degree and no-break space
- added a SemiBold, made by thickening the Regular outlines
- rebuilt kerning in GPOS: upstream capital pairs kept, lowercase pairs replaced
- new vertical metrics to fit descenders and accented capitals
- added WOFF2/WOFF webfonts and a CSS @font-face stylesheet

10-11 November 2021 (Roger Sperberg) Foundation Logo version 0.3
- created Github repository with ttf and source files, OFL and other information files and samples
- initial release to public (but not Github release)
