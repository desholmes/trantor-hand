# Upstream: Foundation Titles Hand

`upstream/` is a copy of [rsperberg/foundation-titles-hand](https://github.com/rsperberg/foundation-titles-hand) at commit `1c7b784` (22 Nov 2021), trimmed to what the build and licence need: the v0.85 TTFs, the original iFontMaker sources and the licence and font-log files. The sample images, the title-sequence reference frames and the older font versions were removed; the images in `upstream/README.md` link to the original repo.
