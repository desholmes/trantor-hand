FONTLOG for the Trantor Hand font

This file provides detailed information on the Trantor Hand font software. This information should be distributed along with the Trantor Hand font and any derivative works.

Basic Font Information

Trantor Hand is a modified version of Foundation Titles Hand v0.85 by Roger Sperberg (https://github.com/rsperberg/foundation-titles-hand), which is based on the character design used in the title sequence of Foundation, an Apple TV+ series. As required by the SIL Open Font License, it is published under a different name because "FoundationTitlesHand" is a Reserved Font Name.

The upstream font contains capitals, figures and Basic Latin punctuation; its lowercase slots held copies of the capitals. Trantor Hand adds a true lowercase and the characters needed for UK English.

Supported Unicode: U+0020-007E, U+00A0, U+00A3, U+00B0, U+00C0-00C2, U+00C4, U+00C7-00CF, U+00D1-00D4, U+00D6, U+00D9-00DC, U+00E0-00E2, U+00E4, U+00E7-00EF, U+00F1-00F4, U+00F6, U+00F9-00FC, U+0131, U+2013-2014, U+2018-2019, U+201C-201D, U+2022, U+2026, U+20AC (the SemiBold also has the upstream U+00A2).

Weights: Regular (400) and SemiBold (600).

Trantor Hand, Trantor Caption and Trantor Mark make up the Trantor font series (https://github.com/desholmes/trantor-type). They are fan-made fonts based on lettering seen in Foundation, the Apple TV+ series based on the Isaac Asimov books, and are not affiliated with or endorsed by Apple, Skydance or the Asimov estate.

ChangeLog

28 October 2026 Trantor Hand version 1.000
- renamed from Foundation Titles Hand (Reserved Font Name)
- added a lowercase a-z in both weights, drawn as centre-line skeletons and stroked to match the capitals
- added accented vowels, c cedilla and n tilde (lower and upper case), dotless i, pound sterling, euro, ellipsis, bullet, degree and no-break space
- added stylistic set ss01 (dotted o, crossed w)
- rebuilt kerning in GPOS: upstream capital pairs kept, lowercase pairs replaced
- new vertical metrics to fit descenders and accented capitals
- added WOFF2/WOFF webfonts and a CSS @font-face stylesheet

1-2 November 2021 (Roger Sperberg) Foundation Titles Hand, both weights, version 0.85
- brought character set up to Basic Latin
13 October 2021 (Roger Sperberg) Foundation Titles Hand version 0.8
- added semibold version
10-11 October 2021 (Roger Sperberg) Foundation Titles Hand version 0.8
- created Github repository with ttf and source files, OFL and other information files and samples
- initial release
