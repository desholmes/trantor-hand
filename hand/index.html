About

Trantor Hand builds on Foundation Titles Hand v0.85, a hand-drawn font based on the title credits of the Apple TV+ series Foundation. The original has capitals, figures and punctuation; its lowercase was a copy of the capitals. Trantor Hand adds:

  • a new lowercase a–z, drawn in the same rounded, single-weight style as the capitals, in Regular and SemiBold;
  • accented letters for UK English loanwords such as café, naïve, rôle, façade and señor;
  • £, €, …, •, ° and a no-break space;
  • kerning for the lowercase;
  • an optional stylistic set (ss01) with the dotted o and crossed w of the title-sequence capitals.

Use it for titles, headings and short passages of text.

Using the fonts

On the web

Self-host the webfonts/ folder from the download and include its stylesheet, or load it from jsDelivr pinned to a release:

<link rel="stylesheet" href="/fonts/trantor-hand.css">
<!-- or -->
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/desholmes/trantor-type@v1.0.0/fonts/hand/webfonts/trantor-hand.css">
body { font-family: "Trantor Hand", sans-serif; }   /* Regular, 400 */
strong, h1, h2 { font-weight: 600; }                 /* SemiBold */
.titles { font-feature-settings: "ss01"; }           /* dotted o, crossed w */

To speed up the first paint, preload the WOFF2 you use above the fold: <link rel="preload" href="/fonts/TrantorHand-Regular.woff2" as="font" type="font/woff2" crossorigin>.

On the desktop

Install the TTFs from the download's ttf/ folder (double-click on macOS, right-click → Install on Windows). In design apps the dotted o and crossed w appear as stylistic set 1.
