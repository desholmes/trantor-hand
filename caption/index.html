About

Trantor Caption builds on Foundation One v0.4, based on the lettering Foundation sets over a scene to mark a new place or time: “Synnax”, “400 years earlier”. Its capitals have distinctive S, M, U, W, B, K and G shapes, and dots stand in for the bars of A, E, F and H. The original was capitals only, in one weight. Trantor Caption adds:

  • a lowercase a–z built the same way: rounded-rectangle bowls, square-shouldered arches, flat stroke ends and a dot for the bar of f;
  • a SemiBold, made by thickening the Regular;
  • the Basic Latin symbols the original lacked ($ % * ^ _ ` ~);
  • accented letters for UK English loanwords, £, €, …, •, ° and a no-break space;
  • kerning for the lowercase;
  • an optional stylistic set (ss01) with an e that has a dot in place of its bar, like E. It is harder to read in running text, so keep it for display.

Use it for labels, captions and short lines. For the on-screen look, set it in capitals with a little extra spacing.

Using the fonts

On the web

Self-host the webfonts/ folder from the download and include its stylesheet, or load it from jsDelivr pinned to a release:

<link rel="stylesheet" href="/fonts/trantor-caption.css">
<!-- or -->
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/desholmes/trantor-type@v1.000/fonts/caption/webfonts/trantor-caption.css">
body { font-family: "Trantor Caption", sans-serif; }   /* Regular, 400 */
strong, h1, h2 { font-weight: 600; }                 /* SemiBold */
.caption { font-family: "Trantor Caption", sans-serif;
           text-transform: uppercase; letter-spacing: 0.04em; }
.display { font-feature-settings: "ss01"; }          /* dotted e */

To speed up the first paint, preload the WOFF2 you use above the fold: <link rel="preload" href="/fonts/TrantorCaption-Regular.woff2" as="font" type="font/woff2" crossorigin>.

On the desktop

Install the TTFs from the download's ttf/ folder (double-click on macOS, right-click → Install on Windows). Use it in capitals for labels and captions, as on screen.
