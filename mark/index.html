About

Trantor Mark builds on Foundation Logo v0.3, based on the logo of the Apple TV+ series Foundation. Only the letters of “Foundation” appear in the logo; the rest of the original's capitals, figures and punctuation were conjectured in the same circular, flat-ended style, with the logo's wide spacing built in. Trantor Mark adds:

  • a lowercase a–z built the same way: circular bowls, flat stroke ends, and E's dot in place of the bar of e;
  • a SemiBold, made by thickening the Regular;
  • accented letters for UK English loanwords, £, €, …, •, ° and a no-break space;
  • kerning for the lowercase;
  • the alternate E F K P S W X Y Z from the series' second, thinner logo, as stylistic set 1 (ss01, also salt).

Use it for wordmarks and a few large words. The wide spacing is part of the design; for longer lines, tighten it with letter-spacing.

Using the fonts

On the web

Self-host the webfonts/ folder from the download and include its stylesheet, or load it from jsDelivr pinned to a release:

<link rel="stylesheet" href="/fonts/trantor-mark.css">
<!-- or -->
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/desholmes/trantor-type@v1.0.0/fonts/mark/webfonts/trantor-mark.css">
body { font-family: "Trantor Mark", sans-serif; }   /* Regular, 400 */
strong, h1, h2 { font-weight: 600; }                 /* SemiBold */
.wordmark { font-feature-settings: "ss01"; }        /* thinner-logo capitals */
.tight { letter-spacing: -0.12em; }                  /* less of the logo spacing */

To speed up the first paint, preload the WOFF2 you use above the fold: <link rel="preload" href="/fonts/TrantorMark-Regular.woff2" as="font" type="font/woff2" crossorigin>.

On the desktop

Install the TTFs from the download's ttf/ folder (double-click on macOS, right-click → Install on Windows). In design apps the alternate capitals appear as stylistic set 1 and in the alternates (salt) picker.
