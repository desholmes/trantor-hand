Using the series

One stylesheet loads every family and weight; browsers only download the files a page uses. Self-host the fonts/ folder, or load it from jsDelivr pinned to a release:

<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/desholmes/trantor-type@v1.0.0/fonts/trantor.css">
h1, h2 { font-family: "Trantor Mark", sans-serif; font-weight: 600; }
body   { font-family: "Trantor Hand", sans-serif; }
.label { font-family: "Trantor Caption", sans-serif;
         text-transform: uppercase; letter-spacing: 0.04em; }

Each family's page has its own stylesheet, stylistic sets and desktop install notes.
